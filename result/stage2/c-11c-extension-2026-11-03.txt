# 11c extension after A's 11a — 2026-11-03

## Scope

- Trigger: A delivered `11a_master_migration.sql` (2026-11-01) with four new
  query/registration procedures. The frozen `11c` whitelist still had 53 codes
  and could not represent them under the invariant
  `Permission = whitelist = role_* GRANT targets`.
- A's four procedures and contract grants (`application-contract.md` §2.4.5):
  - `sp_list_master_records` -> `role_store_manager`
  - `sp_list_sale_products` -> `role_cashier`
  - `sp_find_customer_for_order` -> `role_cashier`
  - `sp_register_customer_for_order` -> `role_cashier`
- C's `11c` was extended from **53 / 66** to **57 codes / 70 RolePermission
  rows** (four `Permission` rows and four role mappings). The actual GRANTs
  remain in `12_permissions.sql`.
- The drill used a real v0.1 deployment and a real 25-table capture batch 1
  (A/B/C baseline files); no domain stub was used.

## Phase 1 — first-round differences and attribution

1. **D1 — whitelist gap.** The A procedures were absent from the 53-code
   `CK_Permission_permission_code` list. Attribution: A's `11a` arrived after
   the 2026-10-31 freeze inputs; the 10-31 list covered only B's six queries and
   C's context. Fix: add four codes, their names, four role mappings, and update
   the terminal counts to 57/70.

2. **D2 — rollback fixture false 3930.** The first rollback harness put the
   expected-failure `EXEC dbo.sp_get_current_employee_context` (THROW 51004)
   inside the outer migration transaction. `THROW` + `XACT_ABORT` made the
   outer transaction uncommittable; a later statement reported Msg 3930.
   Attribution: fixture design, not `11a`/`11c`; H16. Fix: move the negative
   case outside the outer transaction. A separate check on the committed
   partial v1.0 confirms 51004.

3. **D3 — B 13b execution context.** `13b_order_baseline_check.sql` has no
   `USE KFC_DB` and uses `FOR XML PATH`/filtered-index metadata, so running it
   without `-d KFC_DB -I` produced 51960 (master) or Msg 1934
   (`QUOTED_IDENTIFIER`). Attribution: B's file intentionally says "run in the
   target database" and does not set the option; C's regression runner must set
   `QUOTED_IDENTIFIER ON` / `-I`. Fix: rerun with `-d KFC_DB -I`; 5/0.
