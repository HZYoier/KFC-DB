the real function before the patch and calling it in test 09.

These tests use fake DB contexts; they do **not** prove a real employee SQL
login, real `sp_get_current_employee_context` result sets, or inventory/customer
pages. Real login needs the C deployment template and server SQL login
mapping; the full 2.2 path still waits for B's `11b`. OI-14 remains open.
