## 4. 决策记录与边界

- 将本次范围限定为已批准的 B 文档，不执行正式迁移/应用；若把草稿误作冻结方案会造成跨域返工，所以各文档显式标明状态。
- 总额建议保留，但没有执行改表；积分事件值按固定公式承认反规范化，公开维护成本而非宣称严格 3NF。
- I-B08 是教学提示与实际下单策略的待解释差异，不能单方面认定必须支持重复顶层商品。B 提供材料，C 汇总状态并组织确认。
- PointLedger 理论分解有无损/依赖保持论证，不等于决定新增金额倍率字典；当前推荐保留事件值。
- 不把 Customer 累计分假定为本库流水和，也不要求 A 与 B 对两种冗余采取相同措施；若未来发现期初/调整来源，须纳入独立口径。
